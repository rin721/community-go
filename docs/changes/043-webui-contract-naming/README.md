## 范围

本变更纠正 042 使用 `admin` 表示 WebUI 宿主、扩展契约、HTTP 前缀、CLI、Session 和持久化对象的问题。项目自有技术命名统一选择 `webui`，使名称直接表达“浏览器管理界面及其装配契约”，不再把某类使用者角色当作系统边界名。

实施采用单轨替换：不保留 `admin` 包、别名、旧路由、旧 CLI、旧 Cookie、旧表名、兼容分支或双份生成物。042 保留为历史任务证据，并明确由本变更取代其当前技术命名。

## 当前结论

- Auth 仍拥有本地用户、密码和 Session 行为，但面向该宿主的类型、包、路由和存储命名使用 `webui`。
