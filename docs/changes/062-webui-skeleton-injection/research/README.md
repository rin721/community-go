# 062 研究档案

## 研究范围

本变更要回答两个核心问题：

1. 当前 WebUI 骨架、注入面、导航与交互规范的实现事实是什么，与「骨架分区 + 类型化注入点 + 统一交互/权限契约」的目标差距在哪里？
2. 「骨架 + 注入点」适合采用哪种承载架构：继续扩展现有自研静态插拔机制，还是引入微前端运行时或 headless 组件库？结论的证据是什么？
