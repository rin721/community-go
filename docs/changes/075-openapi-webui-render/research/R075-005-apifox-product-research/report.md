# R075-005 Apifox 产品形态与技术拆解

## 研究问题

用户要求 openapi 模块与 Apifox「骨架、交互、设计完全一模一样（非最小可用）」，作为商业级 SaaS 前端搭建，具体点名：左侧资源管理树、顶部全局搜索与工具栏、中间多标签页（项目/文档/调试）、右侧响应结果面板；参数表单自动构建（JSON 输入框、文件上传、Query 参数）；JSON 响应高亮；加载动画、交互高亮、面包屑、状态码与响应时间可视化、深链路由。需拆解：Apifox 的产品形态、设计语言、交互逻辑、OpenAPI→UI 映射理念，以及如何在我们模块内还原。

## 方法与范围

- 官方公开物料：抓取 `https://apifox.com/` 与 `https://apifox.com/help`（2026-08-25，返回 200 的静态文本）；docs 门户为客户端渲染 SPA，无法服务端爬取深层页面（局限）。
- 证据三级标注：**官方物料**（当日抓取原文）＞ **作者产品知识**（Apifox 2.x/3.x 桌面与 Web 版界面是业内公认形态，本会话无可视化对照，标为知识）＞ **推断**。
- web_search 工具本会话不可用（API key 鉴权失败），外部证据全部来自可直连主源；已设置刷新触发器。

### 官方物料（帮助文档，2026-08-25 抓取，节选）

- 快速入门：打开后出现自动创建的项目与示例接口；点击左侧搜索框旁边的 + 号新建接口；导入 Swagger（文件/URL 导入 json 或 yaml）；"快捷请求"（输入完整地址与参数，自动识别 URL 中包含的请求参数并展示在请求参数列表中，点击发送获取响应，可保存为接口）；支持丰富快捷键。

### 作者产品知识（Apifox 界面公认形态，标注为知识）

- **信息架构**：团队 → 项目 →（模块/文件夹）→ 接口/数据模型/环境管理；左侧两级：窄图标栏（桌面版）+ 项目资源树面板。
- **工作台骨架（用户点名的四区）**：顶部工具栏（全局搜索、环境下拉、新建/导入、账号）；左侧资源树；中间多标签页（每接口一标签，可关闭、激活高亮）；主区接口详情（URL 输入栏：方法下拉 + BaseURL + 路径 + 发送按钮；「文档/调试」双模式）。
- **调试页**：标签组 Query / Body / Headers / Cookies / Auth / 前置操作 / 后置操作；Body 支持 JSON / 表单（form-data，可文件上传）/ x-www-form-urlencoded / 二进制；参数表格（参数名/类型/必填/默认值/说明/操作列，行内增删与启用开关）；发送后响应面板（状态码彩色徽标、响应时间 ms、响应大小、响应体多视图：JSON 高亮/HTML/原始、响应头列表）。
- **文档页**：接口说明（含 Markdown 渲染）、请求参数表（只读版）、返回示例（响应体带高亮）、错误码表等。
- **视觉语言**：白底 + 浅灰面板（#F5F6F7 级）、细边框（#DDD/E5E6EB 级）、主色蓝（Apifox 品牌蓝，约 #3370FF 区间，红蓝绿黄为辅色）、紧凑密度（正文 12-14px、行高 1.4-1.6、控件高 28-32px）、小圆角（2-6px）、方法标签色（GET 绿 / POST 蓝 / PUT 橙 / DELETE 红 等，近似色阶与常见 API 工具一致）、选中态浅蓝底、hover 灰底、加载骨架/旋转指示、标签页细边框下划线高亮。
- **交互细节**：树节点点击开标签；顶部 Cmd+K/⌘K 全局搜索跳转；URL 输入自动识别 {param} 与 query；发送按钮 loading 态；响应面板即时渲染；面包屑（项目/模块/接口）；在线文档支持 URL 直达接口（深链）。

### 技术选型公开信息

- Apifox 不开源，官方未公开组件库选型细节（不可复核，记为未知）；客户端为桌面形态（Electron 类），Web 版为自研前台。**我们不复制其私有实现**，只复刻公开可见的设计语言与交互逻辑——这是商业级还原的可行边界。
- OpenAPI→UI 映射理念（推断+知识）：`paths`→目录树/文件夹（`tags` 分组），`operations`→接口条目，`parameters`→Query/Path 参数表格，`requestBody.content`→Body 面板（JSON schema→自动表单 + 样例），`responses`→文档返回示例与执行响应预期，`components.schemas`→数据模型库，`security`→Auth 面板。

## 结论

- 【架构重构（模块内）】`openapi` 页重做为 **Apifox 复刻工作台**（替换 R075-004 的平台组件工作台；R075-004 的执行器/纯函数层/快照链继续复用）：
  - 布局：左侧资源树（搜索、tag 分组、展开/选中、面包屑）+ 顶部工具栏（Cmd+K 全局搜索、环境下拉、新建/深链）+ 中间多标签页（接口文档/调试标签、模型标签，可关闭/激活高亮）+ 主区接口详情（URL 栏 + 文档/调试双模式）与右侧/底部响应面板（状态码徽标、耗时、大小、JSON 高亮、响应头）。
  - 设计语言：模块内自绘 **Apifox 设计 token**（灰阶/主色/间距/字号/圆角/方法色/选中态/阴影），以此实现像素级一致的样式，替代平台组件工作台的通用观感（正式取代 R075-004 的「页内组件全部来自 @webui/sdk/ui」约束 —— 仅 openapi 模块呈现层调整，宿主与其它模块不受影响）。
  - 交互：多标签开合、URL 参数自动识别、参数表格行内编辑/增删/启停、Body JSON/表单(文件上传)/urlencoded、发送 loading→响应即时渲染、加载骨架、键盘快捷键、交互高亮、深链 `?op=&mode=docs|debug`。
- 【依赖候选】JSON/代码高亮采用成熟轻量库 highlight.js（MIT、维护活跃、按需语言），实施期核验版本与体积；不引入 Monaco 级重型编辑器。
- 【保留复用】`webui generate` 快照链、`openapi-data` 解析与请求构建、执行器语义（bearer 内存 token / session Cookie + CSRF）、mock 执行禁用、深链基线。
- **验收路径如实说明**：本会话无 Apifox 体验版可视化/交互对照能力；第一版按公开物料 + 产品知识还原设计语言与骨架，以 Playwright 截图（桌面/移动/亮暗）与手动操作视频作为逐轮校准依据，像素级一致以用户验收为准（刷新触发器已记录）。

## 适用与不适用场景

- 适用：Admin 内 Apifox 式 API 管理（文档/调试/模型/多标签/深链），公开物料可覆盖的视觉与交互层。
- 不适用：Apifox 的团队/权限、自动化测试编排、Mock 服务、CI/CLI、MCP/AI 工作流、多环境变量脚本等需要对应后端能力的商业模块（列入候选方向，不实施）；社群协作与在线文档发布服务。

## 局限与剩余未知

- Apifox 组件库/前端技术栈无官方公开信息（未知）；深层帮助页为 SPA 不可爬（官方物料仅覆盖首页+快速入门文本）；视觉 token 中的精确色值/间距为产品知识级近似，需用户以参照截图/体验版校准。
- 文件上传控件将实现（form-data 能力），但当前后端契约无 multipart 操作（如实标注可用性）。
