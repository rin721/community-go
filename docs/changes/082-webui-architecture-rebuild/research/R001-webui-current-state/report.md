## 4. 当前事实（按 10 个研究问题）

### 4.1 路由模型

**生成链（Go 为主，非前端脚本）**：`webui/scripts/generate.mjs` 依序执行 `scripts/generate-tsconfig.mjs` 与 `go run ./cmd/app webui generate [--check]`（`webui/scripts/generate.mjs:6-13`）。生成逻辑在 `internal/composition/webui_registry.go` 的 `WriteWebUIRegistryFromCurrentDirectory(check)`（39-66 行），输出到 `.scaffold/layout.json` 声明的 `webui.registryOutput`（=`webui/src/generated/webui-registry.ts`）。`--check` 模式做字节级比对，不一致报 `generated file ... is stale`（58 行）。

**生成物形态**（`webui/src/generated/webui-registry.ts`，745 行，`// Code generated by webui-gen; DO NOT EDIT.`）：
- `webuiRevision`（sha256，L3）；
- `webuiEntryRegistry`：27 个 entry ID → `() => import("../../../internal/module/<id>/binding/webui/web/<Page>")` 懒加载（L5-33）；
- `WebUILocaleMessages = Readonly<Record<string,string>>` 类型（L35）；
- `webuiLocaleRegistry`：en-US/zh-CN × 7 个 namespace（webui.auth/iam/navigation/openapi/ops/organization/settings）（L37-56）；
- `webuiMockRegistry`：7 模块 mock.ts 懒加载（L58-66）；
- `webuiZoneRegistry`：zone → 贡献 ID → 懒加载（当前仅 footer-status/header-actions 两组，L68-75）；
- `webuiMockManifest`：mock 环境全量 manifest 快照（L78-753）。

**模块 facet 如何声明路由**：每个模块 `internal/module/<id>/binding/webui/binding.go` 返回 `webui.Binding`（`internal/webui/contract.go:117-140`），其中 `Routes: []webui.Route`、`Navigation: []webui.Navigation`、`Entries`、`Locales`、`MockSource`、`ActionPermissions`、`Requires`。以 IAM 为例：`internal/module/iam/binding/webui/binding.go:10-45` 声明 8 个 entry、8 条 Route（`/setup`、`/login` 为 blank 布局；`/account/security`、`/admin/*` 为 app 布局带 `ViewOperationID`）、7 个 Navigation（`iam.access` 顶级组 + 6 子项）、16 个 ActionPermission、Requires（runtime/http/i18n/ui/mock major 1）。
- Route 结构：`{ID, Path, EntryID, TitleMessageID, ViewOperationID, Layout(app|blank), GroupLayoutID, DeliveryState, DegradedCapabilities, Default, UnauthenticatedDefault}`（`internal/webui/contract.go:149-164`）。
- Navigation 结构：`{ID, ParentID, RouteID, TitleMessageID, IconID, Order}`（167-174 行）。`ParentID` 支持跨 owner 引用（070），环/未知父由 `validateNavigationCycles`/全量校验拒绝（L1102-1120、L1196-1222）。
- 校验：route path 必须以 `/` 开头且无 query/fragment（`validPath`，L1224-1227）；path 全局唯一（L983-985）；category: 声明 Routes 的模块必须同时声明 locale + mock（L952-957）；`Requires` 必须命中 `SDKInventory` 且 major 一致（`validateSDKRequirements`，L733-752）。
- 组合点：`internal/composition/http_contracts.go:60-68` 显式列出 7 个模块 registration（全部 `ActivationEnabled`），`applicationWebUISDKInventory()` = {runtime:1, http:1, i18n:1, query:1, ui:1, mock:1, zone:1}（71-81 行）。`BuildApplicationCatalog` 会剔除 disabled 模块与 not-implemented route（`contract.go:359-386`、`projectImplementedRoutes` L754-799）。

**运行时路由装配（前端）**：`webui/src/App.tsx` 不持有任何路由声明，全部来自运行时 Manifest：
- 启动：`Promise.all([refreshManifest(), loadSession()...])`（App.tsx:28-30）；`manifest.catalogRevision !== webuiRevision` 时进入 StartState 失败态（L51）；revision 门禁防止生成物与后端不同步。
- `Routes` 三层：blank 布局路由（`layout==="blank"`，login/setup）→ AppShell 下 `renderAppRoutes`（app 布局；带 `groupLayoutId` 的一族路由由 `ModuleGroupLayout` 承载，懒加载布局 + `<Outlet>` 注入 children，L58-87）→ 根重定向 `RootRedirect` 与 `*` 兜底（L53、L144-147）。
- `ManifestPage` 访问门禁：`authentication-required` → 跳 login；`denied` → `/403`；`not-implemented` → notImplemented 状态页；不可 loadable（availability）→ unavailable 状态页（L93-104）。`RouteResourceBoundary` 先加载 route locale（`ensureRouteLocale`）再渲染（L111-122）。

**当前页面/菜单层级（以生成物 snapshot 为准）**：
- 24 条路由 / 7 模块：auth 1（`/admin/audit`）、iam 8（`/setup`、`/login`、`/account/security`、`/admin/{accounts,roles,permissions,sessions,api-tokens}`）、navigation 1（`/admin/menus`）、openapi 1（`/openapi`）、ops 2（`/dashboard` 默认、`/dashboard/capabilities`）、organization 3（`/admin/{departments,positions,account-organization}`）、settings 8（`/settings/{profile,account,security,appearance,notifications,language,about,acknowledgement}`，共享 `groupLayoutId: settings.layout`）（`webui-registry.ts:81-416`）。
- 菜单 25 节点，形状：4 个顶级组（`ops.dashboard` 下挂 `ops.capabilities`；`settings.center` 下挂 8 分区；`iam.access` 下挂 6 项；`organization.directory` 下挂 3 项）+ 3 个平铺项（`auth.audit`、`navigation.menus`、`openapi.docs`）（L417-636）。菜单树递归组装、无宿主硬编码：`buildMenuTree` 按 `parentId` 组装（`webui/src/components/shell/SidebarMenu.tsx:12-22`），manifest 侧已按 `Order` 稳定排序（`contract.go:498-504`）并 `retainMenuWithVisibleParents` 裁剪不可达祖先（L709-731）。
- 默认路由：`ops.dashboard` `default: true`（registry L257）；`iam.login` `unauthenticatedDefault: true`（L133）。首页由 `navigateToDefault`/`RootRedirect` 综合 access+delivery+loadable 选择（App.tsx:31-35、138-142）。
- 深链约定：以 path 深链为主（settings 分区、admin 页面）；OpenAPI 工作台使用 query 深链 `?op=&mode=`（`internal/module/openapi/binding/webui/web/OpenAPIPage.tsx:23,29-37`，popstate 恢复 L74-86）；全局 Cmd/Ctrl+K 路由搜索仅列出可访问路由（`components/AppShell.tsx:85-89`、`components/RouteSearch.tsx`）。

### 4.7 权限呈现

- **声明**：模块 Binding `ActionPermissions`（operation ID 集合，如 iam L28-45、organization L19-25、navigation L10、ops L34）；Manifest 投影 `actionPermissions`：按 operation 做 access 判定并保留从严结果（denied > authentication-required > allowed，`contract.go:480-486`、`accessRank` L544-554），排序稳定输出（L556-564）。
- **按钮级投影**：`useActionAccess(operationId)` 读取 manifest.actionPermissions（`sdk/zone/index.tsx:43-50`；未声明/未投影返回 undefined＝前端不做呈现限制）。`ActionTrigger`（`ui/index.tsx:310-343`）把 access 与 pending/disabledReason 合并：denied 时按 `deniedBehavior` 隐藏（默认）或禁用；`onAction` 返回 Promise 时自动 pending 防重复；`data-action-state` 状态标记。示例见 `AccountsPage.tsx:85-100`（create/roles.replace/status/password.reset/update/archive 全部挂 operationId）。
- **菜单 manifest 门槛**：菜单项只在落地 route 通过 access（allowed）+ availability（available/degraded 且能力非空）门禁后投影（`contract.go:442-457`）；不可见父链被裁剪（L709-731）。zone 贡献带 OperationID 时 denied 直接不投影（L473-478）。
- **denied 呈现**：路由访问 denied → `/403` SystemStatePage；authentication-required → 跳 `/login`（App.tsx:94-98）；动作 denied → ActionTrigger 隐藏/禁用；not-implemented/unavailable → 对应状态页（App.tsx:99-100）。
- 语义边界：Manifest 权限投影是**呈现控制**，服务端授权继续 fail closed（`contract.go:132-134` 注释、README 066）。
