# 088 需求

支撑研究：[R088-001](research/R088-001-implementation-research-duplication/report.md)。

## 目标

让研究门禁产生的事实和方案证据在同一任务的实施阶段直接复用，防止阶段切换触发无条件的全量代码复核和重复方案研究。

## 验收标准

- `REQ-088-001`：根规则明确研究门禁通过后形成可复用实施基线。
- `REQ-088-002`：实施入口只比较快照后相关变更与 `refresh_triggers`，未命中时禁止全量复研。
- `REQ-088-003`：命中触发器时只定向复核受影响结论，只有前提失效才返回研究或计划。
- `REQ-088-004`：失败用例、运行态复现和修改后测试明确归类为实施验证，不得无条件扩展为全仓研究。
- `REQ-088-005`：规则不降低对用户已有修改的保护，不跳过修改后必要验证。

## 范围与非目标

本任务只修改仓库协作规则、研究方法 authority 和 088 证据文档。不修改代码、配置、脚本、测试、生成物或 087 的实施计划；不把“避免重复研究”解释为免除失败用例和回归测试。
