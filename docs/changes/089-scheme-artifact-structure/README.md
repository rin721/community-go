## 状态

- 任务性质：纯文档治理变更。
- 研究门禁：已通过，证据见 `R089-001`。
- 计划与实施：按纯文档例外直接完成，不要求第二次确认。

## 结论

本规则生效后的每个新方案都必须同时包含需求、设计和任务三类产物：

- `requirements/` 面向客户与产品使用方，以目录索引和业务语义分篇记录需求；
- `design/` 面向技术人员，以目录索引和技术语义分篇记录详细设计；
- `tasks.md` 作为唯一完成清单，使用 `- [ ]` 和 `- [x]` 表示未完成与已完成。

历史变更不做批量迁移；产生实质性新方案时，以新变更序号使用当前结构。
