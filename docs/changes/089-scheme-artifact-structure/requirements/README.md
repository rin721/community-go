# 089 客户需求

支撑研究：[R089-001](../research/R089-001-current-scheme-artifact-gap/report.md)。

## 需求摘要

每次建立新方案时，客户都应能单独阅读需求并判断“为什么做、解决谁的问题、包含什么、不包含什么、如何验收”；技术人员应能从独立的详细设计中直接理解实现边界；项目成员应能通过任务清单看到真实完成状态。

## 文档索引

- [方案产物需求](scheme-artifact-requirements.md)：目标、使用场景、范围、约束、非目标和验收标准。

## 受众边界

本目录面向客户、产品负责人和验收方，不展开内部包、函数、调用链或状态机。技术实现见[详细设计](../design/README.md)，完成状态见[任务清单](../tasks.md)。
