# 信息架构与页面蓝图

## 1. 顶层导航

推荐以用户任务而不是代码模块命名：

```text
概览
访问与身份
  账户
  角色与权限
  会话
  API Token
组织
  部门
  岗位
  任职
平台
  导航管理
  API 工作台
运营与安全
  审计日志
  系统状态
设置
```

权限决定叶节点可见性，但导航结构本身稳定。分组标题只组织，不与叶节点争夺 active 状态。Todo 等实验能力只有在产品范围确认后才进入正式导航，避免 Demo 功能污染主信息架构。

## 2. Dashboard 蓝图

```text
PageHeader: 概览 + 时间范围/环境
AttentionStrip: 异常、失败任务、风险变化
KPIGrid: 4 个以内可解释指标
TrendSection: 1—2 个主要趋势 + 口径
OperationalQueues: 待处理账户/Token/会话/组织动作
RecentActivity: 可进入审计的近期事件
```

颜色用于异常严重度和趋势，不用每个 KPI 一个装饰色。没有可靠统计契约的卡片不显示假数；可先以系统健康和最近活动构成真实 Dashboard。

## 3. 账户

### 列表

身份（名称/登录标识）、状态、角色摘要、组织摘要、最近活动、更新时间和行菜单。Toolbar 提供搜索、状态、角色、归档和更多筛选；批量支持状态/归档并完整呈现部分失败。

### 详情

- Overview：身份、生命周期、账户状态和关键事实；
- Access：角色、权限摘要、Token、活跃会话；
- Organization：任职与部门/岗位；
- Activity：受控审计时间线；
- Configuration：可编辑属性和危险操作。

账户详情依赖 P0 聚合投影；未落地前不得用多个请求在浏览器假装原子详情。

## 4. 角色与权限

角色列表突出成员数、权限范围、风险级别和更新时间。角色详情先展示影响摘要，再按权限分类进行选择；高风险权限有解释和差异预览。权限页以 taxonomy/资源-动作矩阵和“被哪些角色使用”表达关系，不只是平铺字符串。

## 5. 会话与 API Token

会话列表突出账户、状态、最近活动、过期边界和当前会话；批量吊销有原因与部分结果。设备/网络字段只显示隐私允许的摘要。

Token 列表突出 owner、状态、scope、最近使用和过期；创建/轮换后的 secret 只出现一次，提供复制确认和关闭前提醒，之后详情不可回显。

## 6. 组织

桌面采用可调整 Tree + Detail/Members 双区，Tree 负责定位，右侧负责节点摘要、成员、子节点和动作。移动端先进入节点列表，再进入节点页。移动节点先预检循环、成员影响和目标状态。任职管理需要反向查询而非逐账户进入设置。

## 7. 审计

列表首要筛选是时间范围、操作者、资源、动作和结果；默认按稳定事件时间倒序。点击事件打开 ResultDrawer，展示事件 ID、correlation、主体、目标、结果和安全上下文，并提供“查看相关事件”。导出进入 Job，不阻塞页面。

## 8. 设置

设置首页展示类别与摘要；进入类别后使用紧凑 SectionNav。页面区分个人偏好、组织策略和系统配置，明确作用域、继承与生效时间。保存栏显示 dirty；高影响系统配置可要求二次确认和审计原因。

## 9. OpenAPI 工作台

### wide

资源搜索/树（可折叠） | 请求编辑、参数与认证 | 响应、schema、历史。面板可调宽，默认比例通过容器宽度计算。

### medium

资源树变 overlay，主区域在请求与响应间保持可见分隔；次要 metadata 折叠。

### compact

顶部 segmented 在“资源 / 请求 / 响应”切换。发送后自动进入响应但保留返回请求的上下文。代码块、schema 与 path 自身滚动/换行。

## 10. 系统状态

当前 typed build/startup/live/ready/diagnostics 先形成“当前健康与诊断”页面；Prometheus 文本提供专业下载/查看入口，不直接解析成未经定义的 KPI。P1 typed time-series 到位后再加入趋势、异常和能力健康。

## 11. 页面—后端依赖标记

| 页面族 | 现有能力可先完成 | P0 依赖 |
| --- | --- | --- |
| 账户列表 | 查询、过滤、批量状态/归档 | facet 一致性、部分结果标准化 |
| 账户详情 | 基础字段与角色可局部展示 | 聚合详情、活动/关系摘要 |
| 角色列表/编辑 | CRUD 与权限分配 | 影响摘要、风险 taxonomy |
| 会话/Token 列表 | 现有列表和命令 | 受控使用/客户端投影 |
| 组织 Tree | 节点 CRUD/移动 | 成员反查、计数与安全预检 |
| 审计列表 | 基础多条件过滤 | event/correlation/time range/detail |
| 系统状态 | 当前快照与诊断 | typed history/aggregation 属 P1 |
| OpenAPI | 现有 registry | 无核心后端阻塞，主要是前端 workbench 重构 |
