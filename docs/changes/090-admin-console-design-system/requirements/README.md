# 后台控制台重设计需求

## 需求摘要

管理员需要一个在不同模块中保持相同操作习惯、能够高效处理大量数据、清楚表达状态和风险、并在桌面与移动设备上都可完成核心任务的正式控制台。

本需求由以下研究支撑：R090-001 当前系统审计、R090-002 布局参照研究、R090-003 后端能力缺口和 R090-004 前端基础复核。

## 文档导航

- [控制台整体体验](console-experience.md)：导航、页面骨架、视觉、响应式和状态反馈。
- [后台管理工作流](admin-workflows.md)：列表、详情、表单、批量操作、仪表盘和工作台。
- [后端支撑能力](backend-enablement.md)：为完整前端体验需要补齐的产品能力。

## 范围

覆盖现有认证、IAM、组织、导航、审计、运维、设置与 OpenAPI 工作台。首轮不增加未经验证的新业务模块，也不以静态演示页面或假数据替代真实流程。

## 验收层级

- P0：正式产品基线，必须在本方案完成前满足。
- P1：显著提升效率，按后端依赖和页面价值分阶段交付。
- P2：规模化能力，只有真实业务量和使用场景成立后实施。
