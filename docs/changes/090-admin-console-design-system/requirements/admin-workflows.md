# 后台管理工作流需求

## 1. 资源列表

### WF-090-001 统一查询工作区（P0）

账户、角色、会话、Token、组织成员、审计等资源列表应采用一致的标题、查询、筛选、排序、刷新、分页和新建入口。活动筛选条件必须可见、可单独移除，并可通过 URL 分享和恢复。

### WF-090-002 高效数据阅读（P0）

- 列按业务重要性排列，数字对齐，状态使用轻量标签，主要标识可直接进入详情。
- 列表支持适合数据量的服务端分页/游标、排序与过滤。
- 用户可在合理范围内调整密度和列显示；关键身份列与操作列不因横向滚动失去上下文。
- 无记录与无匹配使用不同反馈。

### WF-090-003 批量操作（P0）

选择记录后出现稳定的批量操作栏，明确选择数量、影响、可撤销性和取消入口。执行后逐项展示成功与失败；失败项可导出或重试，不用一个 Toast 隐藏复杂结果。

## 2. 实体详情

### WF-090-004 业务摘要（P0）

账户、角色、Token 等核心实体拥有可直接访问和分享的详情页。详情首屏展示身份、当前状态、风险/异常、关键关系和最常用操作，而不是一组无层级字段。

### WF-090-005 关系与活动（P1）

详情按“概览、访问/关系、活动、配置”组织；只显示当前实体适用的页签。关联对象可跳转，活动可按时间理解，危险操作与普通编辑分区。

### WF-090-006 影响预览（P0）

角色权限、组织移动、会话吊销、Token 撤销等有广泛影响的操作，在确认前说明影响对象、不可逆性和预计结果。无法可靠计算影响时不得给出伪精确数字。

## 3. 表单与设置

### WF-090-007 业务语义分组（P0）

创建和编辑页面按用户任务分组字段，例如身份、访问、有效期和安全，而不是按 Input/Select 控件类型分组。字段说明靠近输入，错误精确对应字段。

### WF-090-008 保存状态（P0）

长表单显示未保存状态，保存区在滚动时保持可发现；离开时保护未保存内容。服务端冲突必须说明数据已变化并提供重新加载或比较选项。

### WF-090-009 设置导航（P0）

设置页面使用紧凑、可折叠的分类导航；不能在常见桌面宽度下与全局侧栏共同占据过多空间。每个设置项说明作用范围、默认值和生效时机。

## 4. Dashboard、审计与工作台

### WF-090-010 行动导向 Dashboard（P1）

Dashboard 先呈现需要关注的异常、待处理动作和健康状态，再呈现关键指标与趋势，最后提供近期活动。每个指标说明口径和时间范围，并能进入对应资源列表。

### WF-090-011 可调查审计（P0）

审计列表支持时间范围、操作者、资源、动作和结果筛选。事件详情能按关联标识串联同一请求或操作链，展示经过安全筛选的上下文并允许分享定位。

### WF-090-012 专业 OpenAPI 工作台（P0）

- 桌面可同时浏览资源、请求和响应；各面板尺寸可调整并有最小宽度。
- 平板可折叠资源导航，手机以资源列表、请求、响应分段切换。
- 长路径、schema 和响应不会溢出视口；复制、搜索、错误与 loading 行为统一。
- 单一 OpenAPI 工作台不额外显示无切换价值的宿主页签。

### WF-090-013 全局搜索与命令（P1）

- 全局搜索首先帮助用户找到页面、账户、角色、组织节点和可访问资源；结果按类型分组并说明匹配字段。
- Command 只呈现当前用户、当前上下文和当前对象允许的动作；危险动作不能从命令面板一步执行，仍需进入影响说明和确认流程。
- 页面内 Search 只查询当前资源，不能与全局搜索使用相同外观却产生不同且无说明的范围。
- 常用导航与安全动作支持键盘，但快捷键必须可发现、可关闭且不覆盖浏览器和辅助技术的重要快捷键。

### WF-090-014 可解释数据展示（P1）

- Statistic 必须同时表达指标名称、值、单位、时间范围、更新时间和比较基准；没有基准时不显示伪趋势。
- Chart 只用于趋势、比较、构成、分布或关系确实比数字/表格更易理解的场景。
- 图表提供文本摘要、可访问名称和查看数据入口；不能只依赖颜色、悬浮 tooltip 或动画传递信息。
- 过滤、时间范围和时区在指标、图表与明细之间保持一致；从图表进入列表时保留相同查询上下文。

## 5. 弹窗、抽屉和页面的使用边界

- Dialog 用于短决策、短输入和危险确认。
- Drawer 用于不离开列表即可理解的上下文详情或轻量编辑。
- 多步骤、跨章节、可分享或包含复杂关系的任务使用独立页面。
- 同一任务不得在不同模块随意选择不同容器。
