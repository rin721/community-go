# 全站交互组件单轨需求

- REQ-092-001：截图中的 SearchInput 与 Field 必须同源，并覆盖全站其他同类输入。
- REQ-092-002：宿主、业务模块和 OpenAPI 工作台的通用交互统一使用 HeroUI/RAC 经项目 UI 层提供的契约。
- REQ-092-003：文本、搜索、数字、日期、日期时间、文件、选择、复选、单选、开关、按钮、Tabs、Tree、Disclosure 与命令选择均不得由页面重复实现。
- REQ-092-004：保留现有查询值、日期字符串、文件上传、命令执行、权限、焦点恢复和业务复合结构，不改变后端契约。
- REQ-092-005：源码门禁必须阻止直接原生交互标签、手写复合交互 role 和模块直连组件库回归；必要例外需集中记录，本任务默认无仓库自写原生例外。
- REQ-092-006：亮暗主题、密度、桌面与 390px 下，同类控件的高度、圆角、focus、disabled、error 与 selected 状态一致。
- REQ-092-007：迁移完成后删除旧实现、旧样式和失效测试，不保留双轨兼容层。

非目标：不改变 HTTP、数据库、权限或时区业务规则；不新增组件库；不治理独立 `frontend/`。
